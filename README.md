# #LiteTexs - Iveco Urbanway T7 et C8.
Énième remaster issu de l'ancien format des LiteTexs sous l'ère iwxbe : celui pour les Urbanway issus du DLC Iveco Citybus Family (Tector 7, Cursor 8...). Compatibilité partielle avec les mods de Loic84 (https://reboot.omsi-webdisk.de/file/13607-urbanway-10-en-version-2-portes/) et xavi64520 (https://reboot.omsi-webdisk.de/file/12159-urbanway-12-cursor-2-doors-gnv-voith-mod/).

# Notes:
- Le DLC Iveco Citybus Family est requis et vous le retrouverez bien évidemment sur Steam.

# Installation:
Il suffit juste de glisser le dossier OMSI 2 à la racine du dossier où est présent votre OMSI, ex: steamapps/common.
